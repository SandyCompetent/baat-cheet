Core capabilities

Beyond simple LLM wrappers

ChatBud combines real-time RAG ground truth, multi-agent persona switching, and on-device memory orchestration.

Grounded RAG • Live Public APIs

Real-time Grounding Engine

Eliminates hallucinations by querying live public APIs before generation. Connects directly to real-time currency exchange (Frankfurter & APILayer), global weather (Open-Meteo), verified dictionaries, nutritional databases, and web search with inline citation badges.

Frankfurter FX Open-Meteo DuckDuckGo APILayer Keys
Campus Intelligence

Exeter Academic Agent

Purpose-built agent for University of Exeter students and faculty. Features an interactive Campus Live Sheet with live timetables, library book catalogue, Guild societies, and campus navigation.

Responsive UX

Adaptive Desktop Rail

Seamlessly scales from phone screens to wide 4K displays. Features a dedicated Desktop Navigation Rail, centered distraction-free canvas, physical keyboard shortcuts (Enter to send, Shift+Enter for newline), and multi-column grid layouts.

On-Device Memory

Two-Layer Vector Memory

Powered by vector cosine similarity. Agents automatically extract personal facts and preferences, or you can add them manually, to form a continuous on-device context window across chat sessions.

Stored privately on your device via Flutter Secure Storage & Hive.

16 Curated Persona Agents

Switch personalities on the fly: HR Recruiter, Resume Coach, Technical Copywriter, Grounded RAG Expert, Exeter Academic, and more. Each agent carries tailored system prompts, suggested starter queries, and distinct tone guidelines.
